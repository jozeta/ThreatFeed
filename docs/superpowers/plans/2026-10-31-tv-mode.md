# TV Mode & Dashboard Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full-screen, unattended "TV mode" news wall (newspaper/latest, Briefing, Ransomware) and "Dashboard mode" (Vulns, Ransomware), with a new daily-count history so dashboard trends fill in over time.

**Architecture:** Pure, tested modules build tiles (`src/services/tv/tiles.ts`) and dashboard figures (`src/services/tv/dashboard.ts`) from data the app already holds plus a new `stats.json` history written by the snapshot job. A lazy-loaded overlay (`src/components/tv/`) driven by a `tv`/`dash` hash param renders them full screen, with a rotation hook and CSS transitions.

**Tech Stack:** React 18, TypeScript, Vite, Tailwind, Vitest; SVG charts in-house; Node snapshot script + GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-30-tv-mode-design.md`

## Global Constraints

- No new runtime dependencies, no chart library; reuse `src/components/charts/` helpers (`useWidth`, `monotonePath`).
- Static GitHub Pages site; no backend.
- TV/dashboard UI is lazy-loaded (`React.lazy`); main chunk must not grow by more than ~3 kB gzip.
- Always dark in both modes regardless of app theme; no scrollbars at any 16:9 size from 1280×720 to 3840×2160.
- Font sizes scale with viewport (`clamp()` with `vw`/`vh`).
- Settings: `tvIntervalMinutes` 1–30, default **2**; `tvTransition` `'fade' | 'slide' | 'reveal'`, default **`'reveal'`**.
- Reduce motion (`settings.reducedMotion` or `prefers-reduced-motion`) ⇒ always a plain quick fade.
- 5–6 tiles per set; grid 3 columns × 2 rows; 2×1 wide tiles for the most important stories.
- Ransomware TV: ~1 in 3 tiles is a victim tile; if one kind runs short the other fills.
- Story list frozen for one full cycle; rebuilt at wrap-around.
- `stats.json` keeps **400** days; de-duplicates by CVE id / victim id; durable across deploys like `trends.json`.
- Hide "vs previous" deltas when the previous period has no history.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Few stories (0, 1, 4) on a TV page → no gaps: tiles grow; 0 ⇒ calm "No new stories" screen with the clock (tests in Task 2).
2. Tab hidden for an hour, then shown → rotation resumes from where it was, no burst of transitions (Task 4 hook test).
3. Fullscreen refused (opened from a kiosk URL with no user gesture) → overlay still covers the viewport, × still exits (Task 3 manual check + unit test of the fallback flag).
4. `stats.json` missing/garbled/older-version → dashboards render with what exists, no crash, deltas hidden (Task 1 decode tests, Task 5 tests).
5. Snapshot re-run several times a day → counts don't inflate (Task 1 merge test).

### Task 2: Tile building

**Files:**
- Create: `src/services/articles/importance.ts` (move `calculateImportance` + `getArticleHash` out of `NewspaperView.tsx` verbatim, exported), `src/services/tv/tiles.ts`, `src/services/tv/tiles.test.ts`
- Modify: `src/components/Newspaper/NewspaperView.tsx` (import from the new module; behaviour unchanged)

**Interfaces:**
- Produces:
  ```ts
  export type TvTileKind = 'story' | 'victim' | 'kev' | 'breach' | 'trend';
  export type TvTone = 'critical' | 'high' | 'info' | 'ransomware';
  export interface TvTile { id: string; kind: TvTileKind; tone: TvTone; source: string; time?: string; // ISO
    headline: string; summary?: string; weight: number }
  export interface TvSet { tiles: (TvTile & { col: 1 | 2 | 3; row: 1 | 2 })[] }
  export function tilesForFront(articles: Article[], stackKeywords: string[], now: number, max = 30): TvTile[];
  export function tilesForBriefing(b: Briefing, max = 30): TvTile[];
  export function tilesForRansomware(news: Article[], victims: LeakSiteVictim[], groupNames: string[], now: number, max = 30): TvTile[];
  export function chunkSets(tiles: TvTile[]): TvSet[];
  ```
- `tilesForFront`: articles from the last 24 h, excluding leak-site posts (`isLeakSitePost`), clustered (`clusterArticles`, use the primary article), sorted by `calculateImportance` desc then time desc. `weight` = importance. Tone from severity (critical/high), `ransomware` when tagged ransomware, else `info`. Summary = article summary/description stripped to plain text.
- `tilesForBriefing`: in order — topStories (story), newKev (kev, tone critical, headline `"<CVE> added to CISA KEV"` + vendor/product), ransomware (one tile: `"<count> ransomware victims"` summary top 3 groups), breaches (breach, tone high), trending (trend, tone info). `weight`: top stories 10, KEV 9, ransomware 8, breaches 6, trending 4.
- `tilesForRansomware`: news = articles classified as incidents (`classifyIncident(a, groupNames) === 'ransomware'`, non-leak-site, last 72 h); victims = last 24 h newest first (fallback last 72 h). Interleave so every third tile is a victim (positions 3, 6, 9 …); when one list runs out append the rest of the other. Victim tile headline `"<Group> listed <Victim>"`, summary `"<sector> · <country name>"`, tone `ransomware`.
- `chunkSets`: sets of 6 in order (last set may be smaller). Each tile gets a grid span so the 3×2 grid is always exactly filled:
  | n | spans |
  |---|---|
  | 6 | six 1×1 |
  | 5 | one 2×1 (highest weight) + four 1×1 |
  | 4 | two 2×1 (two highest weights) + two 1×1 |
  | 3 | three 1×2 (tall columns) |
  | 2 | two 3×1 (full-width rows) |
  | 1 | one 3×2 (whole screen) |
  Tiles keep their order within the set; placement order is left to the view (`grid-auto-flow: dense`).

  ```ts
  export function useRotation<T>(build: () => T[], intervalMs: number, opts?: { now?: () => number }):
    { sets: T[]; index: number; phase: 'in' | 'out'; cycle: number };
  ```
  Behaviour: `sets = build()` at mount and again each time `index` wraps to 0 (frozen otherwise). Every `intervalMs` → `phase:'out'` for `OUT_MS` (600 ms; reveal: 600 + 80 ms × tile count) then advance index and `phase:'in'`. - Transitions (classes on set container/tiles): fade (opacity 500 ms), slide (translateX −6vw→0 with opacity), reveal (tiles out together, in staggered 120 ms each, scale .97→1 + opacity). Reduced motion → 200 ms opacity only.

### Task 5: Dashboard figures

**Files:**
- Create: `src/services/tv/dashboard.ts`, `src/services/tv/dashboard.test.ts`

**Interfaces:**
- Consumes: `StatsData`, `dayTotals` (Task 1); `VulnData`, `MsrcData`, `LeakSiteVictim`.
- Produces:
  ```ts
  export interface Figure { value: number; delta?: number } // delta omitted when the previous window has no history
  export interface VulnDashboardData {
    critical7d: Figure; kev7d: Figure; exploits7d: Figure;
    patchTuesday: { total: number; critical: number; zeroDays: number; month: string } | null;
    exploitedNow: { cve: string; score?: number; title: string; tag: 'KEV' | 'PoC' }[]; // max 8, KEV first then score desc
    weekly: { week: string; critical: number; kev: number }[]; // 13 weeks, oldest first
  }
  export interface RansomDashboardData {
    victims24h: Figure; victims7d: Figure; groups7d: { value: number; newThisWeek: number };
    topSector: { name: string; share: number } | null;
    topGroups: [string, number][]; topCountries: [string, number][]; // 7 d, max 5
    daily: { day: string; count: number }[]; // 30 days, oldest first, zeros filled
    latest: LeakSiteVictim[]; // 6 newest
  }
  export function vulnDashboard(v: VulnData | null, msrc: MsrcData | null, stats: StatsData | null, now: number): VulnDashboardData;
  export function ransomDashboard(victims: LeakSiteVictim[], stats: StatsData | null, now: number): RansomDashboardData;
  ```
- Counts: for windows covered by live data use it (victims list, `notable`, KEV `dateAdded`), union with `stats` ids for the same days so the result never goes down when live data is shallower. Previous-window "has history" = `stats` has ≥1 day in that window or live data reaches back that far; else `delta` omitted.
- `exploitedNow`: CVEs in KEV added within 30 days (tag KEV) plus `notable` with `exploits[cve]` having msf/nuclei/pocs (tag PoC), dedupe, title `vendor product` for KEV or description first 60 chars for notable.
- `patchTuesday`: from the latest MSRC release (use the existing `severityImpactMatrix`/release fields; zero-days = exploited flag count).
- `groups7d.newThisWeek`: groups with victims in last 7 d and none in the 7–30 d window before.
